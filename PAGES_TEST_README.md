# Steklo VPN — тест GitHub Pages

Эта ветка предназначена для проверки публикации исходных Xray JSON-конфигураций и метаданных отдельно друг от друга.

## Файлы

- `configs/okeania_auto.txt` — исходный массив из 14 Xray-конфигураций. Не преобразуется и не изменяется.
- `configs/metadata.json` — метаданные профиля Steklo VPN.

## URL после включения GitHub Pages

Если Pages настроен на ветку `test/github-pages-happ`, папку `/ (root)`, адреса будут:

- Конфигурации: `https://oceaniavpn.github.io/StekloVPN/configs/okeania_auto.txt`
- Метаданные: `https://oceaniavpn.github.io/StekloVPN/configs/metadata.json`

## Важно

GitHub Pages отдаёт эти файлы как статические ресурсы. Клиентское приложение должно самостоятельно запросить оба URL: сначала или параллельно получить JSON-конфигурации, затем `metadata.json`, и применить метаданные к интерфейсу профиля.

Happ не объединяет произвольный соседний `metadata.json` с JSON-конфигурациями автоматически. Поэтому этот тест проверяет доступность двух отдельных ресурсов и сохранность исходных конфигов, а не автоматическое отображение метаданных в Happ.

## Проверка

1. В репозитории откройте **Settings → Pages**.
2. В разделе публикации выберите **Deploy from a branch**.
3. Выберите ветку `test/github-pages-happ` и папку `/ (root)`, затем сохраните.
4. После публикации откройте оба URL выше. Первый должен возвращать JSON-массив конфигураций, второй — JSON-объект метаданных.
5. Убедитесь, что в первом файле присутствуют все 14 конфигураций и последний объект-балансировщик.

Основная ветка `main` не затрагивалась.
