# 🌊 StekloVPN Configurations

Публичный репозиторий с подписками OceaniaVPN.

## Как использовать

1. Получи свою персональную ссылку подписки в Telegram боте [@твой_бот]
2. Скопируй raw ссылку
3. Вставь в VPN приложение (v2rayNG, Shadowrocket, Hiddify, Clash)
4. Готово — подписка будет автоматически обновляться

## Поддерживаемые протоколы

- VLESS
- VMess  
- Trojan
- Shadowsocks
